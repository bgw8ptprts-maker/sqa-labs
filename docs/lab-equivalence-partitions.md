# Лабораторная работа: классы эквивалентности и граничные значения

## 1. Цель работы

Изучить методы классов эквивалентности и анализа граничных значений, реализовать функции на Python и проверить их корректность с помощью параметризованных тестов `pytest`.

## 2. Задание 1. Функция grade(score)

Функция принимает целый балл от 0 до 100 и возвращает оценку.

### Таблица классов эквивалентности

| № | Класс значений | Тип | Ожидаемый результат |
|---|---|---|---|
| EC1 | 0–54 | Допустимый | 2 |
| EC2 | 55–69 | Допустимый | 3 |
| EC3 | 70–84 | Допустимый | 4 |
| EC4 | 85–100 | Допустимый | 5 |
| EC5 | Меньше 0 | Недопустимый | ValueError |
| EC6 | Больше 100 | Недопустимый | ValueError |
| EC7 | Дробное число | Недопустимый | ValueError |
| EC8 | Строка или другое значение не типа int | Недопустимый | ValueError |

### Граничные значения

| Метод | Тестовые значения | Количество |
|---|---|---:|
| Двухточечный | -1, 0, 54, 55, 69, 70, 84, 85, 100, 101 | 10 |
| Трёхточечный | -1, 0, 1, 53, 54, 55, 56, 68, 69, 70, 71, 83, 84, 85, 86, 99, 100, 101 | 18 |

Количество рассчитано для переходов между допустимыми диапазонами оценок и внешних границ допустимого диапазона. Повторяющиеся значения учитываются один раз.

## 3. Задание 4. Функция discount(amount)

Функция определяет процент скидки по сумме заказа в сумах.

### Таблица классов эквивалентности

| № | Сумма заказа | Тип | Результат |
|---|---|---|---|
| EC1 | 1–99 999 | Допустимый | 0% |
| EC2 | 100 000–499 999 | Допустимый | 5% |
| EC3 | От 500 000 | Допустимый | 10% |
| EC4 | 0 и меньше | Недопустимый | ValueError |
| EC5 | Дробное число | Недопустимый | ValueError |
| EC6 | Строка или пустое значение | Недопустимый | ValueError |

### Граничные значения

| Граница | Значения |
|---|---|
| Минимум | 0, 1, 2 |
| Переход к скидке 5% | 99 999, 100 000, 100 001 |
| Переход к скидке 10% | 499 999, 500 000, 500 001 |

Для трёхточечного метода используется значение непосредственно до границы, сама граница и значение непосредственно после неё.

## 4. Задание 5. Поле «Количество товара»

Допустимое значение: целое число от 1 до 99 включительно.

### Таблица классов эквивалентности

| № | Класс | Пример | Тип |
|---|---|---|---|
| EC1 | Целое число 1–99 | 10 | Допустимый |
| EC2 | Меньше минимума | -3, 0 | Недопустимый |
| EC3 | Больше максимума | 100 | Недопустимый |
| EC4 | Дробное число | 2.5 | Недопустимый |
| EC5 | Текст | "abc" | Недопустимый |
| EC6 | Пустая строка | "" | Недопустимый |

Минимальное количество тестов по одному представителю на класс: 6. Дополнительно следует проверить границы 0, 1, 2, 98, 99 и 100.

## 5. Задание 6. Проверка пароля

Требования: длина пароля от 8 до 20 символов, наличие хотя бы одной цифры.

### Таблица классов эквивалентности

| № | Условие | Пример | Тип |
|---|---|---|---|
| EC1 | Длина меньше 8, цифра есть | "abc1234" | Недопустимый |
| EC2 | Длина 8–20, цифра есть | "abc12345" | Допустимый |
| EC3 | Длина больше 20, цифра есть | "abcdefghijklmnopqrstu1" | Недопустимый |
| EC4 | Длина 8–20, цифр нет | "abcdefgh" | Недопустимый |

Минимальный набор содержит 4 теста. Каждый недопустимый класс проверяется отдельно, остальные условия при этом остаются допустимыми.

### Граничные значения длины

| Граница | Длина | Ожидаемый результат |
|---|---:|---|
| Ниже минимума | 7 | Отклонить |
| Минимум | 8 | Принять при наличии цифры |
| Выше минимума | 9 | Принять при наличии цифры |
| Ниже максимума | 19 | Принять при наличии цифры |
| Максимум | 20 | Принять при наличии цифры |
| Выше максимума | 21 | Отклонить |
